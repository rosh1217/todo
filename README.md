# Todo Master

A premium, production-ready Todo List application built with vanilla JavaScript, Express, and a JSON file database. Features glassmorphism, dark mode, and full CRUD operations.

## Features

- ✨ Modern glassmorphism UI
- 🌙 Dark mode toggle
- ➕ Add, edit, delete todos
- ✅ Mark complete / undo
- 🔍 Search todos
- 🗂️ Filter by All / Completed / Pending
- 📊 Statistics (total, completed, pending)
- 🔔 Toast notifications
- 🗑️ Confirmation before delete
- 📱 Fully responsive
- ⚡ Fast and lightweight

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JS
- **Backend**: Node.js, Express
- **Database**: JSON file (data.json)
- **Deployment**: Vercel
